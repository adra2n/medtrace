## 一、优化总览

| 优先级 | 优化项 | 说明 |

| 🔴 高 | 引导页插图 | 首次使用体验 |

## 五、功能图标优化

### 当前状态
- 纯色图标
- 无背景色

### 优化方案

| 功能 | 当前图标 | 优化后 |
|------|----------|--------|
| 就诊记录 | 📋 | 📋 + 蓝色圆形背景 |
| 家庭成员 | 👥 | 👥 + 绿色圆形背景 |
| 提醒功能 | ⏰ | ⏰ + 橙色圆形背景 |
| 数据统计 | 📊 | 📊 + 紫色圆形背景 |

**示例**：
```
┌─────────────────┐
│   ┌─────┐       │

│   └─────┘       │
│   就诊记录      │
└─────────────────┘
```

## 七、设计规范

### 颜色方案
```
主色：#2196F3（蓝色）
辅色：#4CAF50（绿色）
强调色：#FF9800（橙色）
背景：#FFFFFF（白色）
文字：#333333（深灰）
次要文字：#666666（中灰）
```

### 插图风格
- 扁平化设计
- 线条简洁
- 颜色柔和
- 医疗健康主题
- 矢量格式（可缩放）

### 尺寸规范
- 启动页插图：200x200dp
- 引导页插图：180x180dp
- 空状态插图：120x120dp
- 功能图标：24x24dp
