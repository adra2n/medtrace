# 添加家人页面 & 医疗记录页面 UI 重设计

## 一、添加家人页面 (MemberEditDialog) 优化

### 当前问题
- 缺少清晰的分组标题
- 图标使用不够一致
- 布局可以更紧凑
- 必填字段不够明显

### 设计目标
- 添加分组图标增强视觉引导
- 优化布局和间距
- 保持对话框形式但内容更清晰

### 优化方案
1. **分组标题**
   - 👤 基本信息（姓名、关系）
   - 🎂 个人资料（性别、生日）
   - 🏥 健康信息（血型、过敏史、慢性病、用药注意）
   - 📝 备注

2. **图标增强**
   - 性别选项添加图标：♂ 男、♀ 女、⚧ 其他
   - 头像选择区域添加相机图标提示

3. **布局优化**
   - 增加分组间距
   - 标题颜色统一使用 Primary

## 二、医疗记录页面 (MedicalRecordScreen) 优化

### 当前问题
- 顶部栏只有标题，缺少信息
- 搜索栏可以更突出
- 记录卡片布局可以更清晰
- 缺少记录统计

### 设计目标
- 顶部栏添加记录统计
- 搜索筛选区域更突出
- 记录卡片添加图标增强可读性
- 底部 FAB 添加文字提示

### 优化方案
1. **顶部栏**
   - 添加副标题显示记录总数

2. **搜索筛选**
   - 使用 SectionCard 包裹
   - 搜索框添加图标
   - 日期筛选添加图标

3. **记录卡片**
   - 添加成员头像或图标
   - 使用分隔线分隔信息
   - 编辑/删除按钮添加文字

4. **空状态**
   - 添加更友好的提示
