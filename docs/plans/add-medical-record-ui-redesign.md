# 添加医疗记录页面 UI 重设计

## 当前问题
- 成员选择使用下拉菜单，不够直观
- AI 识别区域可以更突出
- 表单布局可以更清晰
- 缺少可视化引导
- 药品列表展示可以更美观

## 设计目标
- 与主页、家人页面保持视觉一致性
- 提高填写效率和用户体验
- 更直观的成员选择
- 更突出的 AI 功能
- 更好的表单组织

## 设计方案

### 1. 顶部栏 (GradientTopBar)
```
[返回]  添加医疗记录          [主页]
        智能识别，快速记录
```

### 2. 家庭成员选择
使用 `MemberSelector` 组件，横向卡片选择，更直观

### 3. AI 智能识别区域
- 使用 SectionCard 包裹
- 更突出的卡片样式
- 图标 + 标题 + 说明
- 大按钮：拍照识别 / 相册选择
- 图片预览网格
- 文本输入框

### 4. 基本信息
- 诊断结果（必填 *）
- 就诊医院（可选）
- 就诊时间（必填）

### 5. 开具药品
- 每个药品卡片更美观
- 更好的间距和布局
- 添加按钮更突出

### 6. 备注
- 简洁的文本框

### 7. 底部操作
- 取消 / 保存按钮

## 视觉元素
- 使用 `SectionCard` 组织内容
- 使用 `MemberSelector` 选择成员
- 统一的颜色方案（Primary 为主色）
- 适当的图标增强视觉引导
