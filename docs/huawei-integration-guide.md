# 华为应用市场上架指南

> 最后更新：2026-07-28

## 一、注册华为开发者账号

### 1. 访问华为开发者平台
- 网址：https://developer.huawei.com/
- 点击"注册"

### 2. 注册流程
1. 填写手机号、验证码
2. 设置密码
3. 完成实名认证（个体户可用营业执照认证）

### 3. 个体户认证
- 上传营业执照照片
- 填写企业信息
- 等待审核（通常1-3个工作日）

---

## 二、创建应用

### 1. 进入开发者后台
- 登录后进入"AppGallery Connect"
- 点击"我的应用" → "添加应用"

### 2. 填写应用信息
| 项目 | 内容 |
|------|------|
| 应用名称 | 医迹 |
| 应用包名 | com.yy.medtrace |
| 应用类型 | Android应用 |
| 类别 | 健康健美 |

### 3. 上传签名证书
- 使用 Keystore 文件生成签名证书
- 上传 `.jks` 文件和密码

---

## 三、应用内支付（IAP）

### 1. 开通 IAP 服务
- 在 AppGallery Connect 中开通"应用内支付"
- 个体户可以使用

### 2. 配置商品
- 商品ID：`medtrace_unlock_all`
- 商品名称：医迹高级版
- 价格：¥9.90
- 商品类型：非消耗品（一次性购买）

### 3. 华为 IAP 特点
| 特点 | 说明 |
|------|------|
| 手续费 | 0%（华为不收取手续费） |
| 结算周期 | T+1 结算 |
| 个体户支持 | ✅ 支持 |

---

## 四、集成华为 HMS Core SDK

### 1. 添加依赖

```kotlin
// app/build.gradle.kts
dependencies {
    // 华为 HMS Core
    implementation("com.huawei.hms:hwid:6.11.0.300")
    implementation("com.huawei.hms:iap:6.11.0.300")
}
```

### 2. 配置 AppGallery Connect

- 下载 `agconnect-services.json`
- 放入 `app/` 目录

### 3. 实现支付功能

```kotlin
// HuaweiPayManager.kt
class HuaweiPayManager(
    private val activity: Activity,
    private val productId: String
) {
    fun startPurchase() {
        val req = PayReq().apply {
            this.productId = productId
            priceType = 0  // 0:非消耗品
            appName = "医迹"
        }
        
        IapClient.getInstance(activity).createPurchaseIntent(req)
            .addOnSuccessListener { result ->
                // 处理支付结果
            }
            .addOnFailureListener { e ->
                // 处理错误
            }
    }
}
```

## 七、注意事项

1. **应用签名**
   - 使用发布证书签名
   - 证书密码妥善保管

2. **隐私政策**
   - 必须是可访问的 URL
   - 内容完整

3. **软件著作权**
   - 个体户可以申请
   - 需要营业执照

4. **应用测试**
   - 提交前充分测试
   - 确保无崩溃
